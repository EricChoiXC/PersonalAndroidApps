# 业务需求

> 本应用为本地应用，不进行联网操作

## 一. 待办

一条待办记录包括：是否完成、待办事项、待办日期 三个内容

### 1.1 创建待办

填写待办事项和待办日期，提交完成创建

### 1.2 删除待办

在待办列表页面复选删除

### 1.3 编辑待办

在待办列表页面点击进入待办事项编辑

### 1.4 完成和取消完成待办

在待办列表页面提供一个复选框表示是否完成，单击更新完成状态

## 二. 组件卡片

组件大小 3*3；组件内容为读取当前日期的待办，分页显示待办事项，并且支持在卡片上直接点击更新对应待办的完成状态

## 三. 设置

提供一个清理预期待办的值。单位（天），默认值 30；每次应用启动时，自动删除已超过对应值天数的待办。填写0或不填写时不删除（需要在不填写时在输入框内背景显示“为0或不填写则不自动清楚”）
