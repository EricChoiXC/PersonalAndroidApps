# 业务需求

> 本应用为本地应用，数据保存在本地应用中，不进行任何联网操作。支持记账、统计查询、数据导出功能

## 一：首页

首页提供三个按钮：记账、统计查询、配置；分别进入到后续页面与业务中

## 二：记账

> 当前应用只实现“手工记账”功能

### 2.1 手工记账

用户进入记账页面后，分别填写以下内容：

| 填写项  | 要求                                           |
|------|----------------------------------------------|
| 类型   | 可选“入账”/“出账”，必选，默认“出账”                        |
| 操作账户 | 从配置的操作账户中进行选择，必选，且根据当前选择的操作账户，自动覆盖“账户号”的当前信息 |
| 账户号  | 文本框输入，非必填                                    |
| 金额 | 文本框输入数字（含小数点），必填                             |
| 账单日期 | 年月日时分范围的日期选择，默认当前时间，必填，提交时不拿当前时间覆盖填写 |
| 标签 | 从配置的标签中进行选择，可多选，非必选                          |
| 备注 | 多行文本框，非必填                                    |

填写完成后提交保存。

## 三：统计与查询

用户进入统计与查询页面，根据以下信息单独或组合查询：

类型；操作账户；金额范围（左闭右闭）；标签（可多选，或匹配）；账单日期（仅限年月日范围，最大日期跨度为1年，可直接按年或按月选择）

## 四：导出

在统计与查询页面上，提供“导出”按钮，在将当前查询条件的所有结果创建到xlsx文件中，并下载到本地的 "/download" 文件夹中，默认文件名为 "账单-${导出操作时间的'yyyyMMdd-HHmmss'}.xlsx"

## 五：配置

用户进入配置页面，可配置操作账户和标签，初始提供以下默认项：

操作账户：储蓄卡、信用卡、支付宝余额、微信钱包、其他

> 除了操作账户名称外，还提供一个额外的账户号字段；当用户记账中点选对应操作账户时，该账户号自动覆写到账户号上；初始提供的操作账户的账户号为空，用户可编辑

标签：餐饮、交通、服饰、转账、生活水电、电子用品、购物、大宗商品、其他
