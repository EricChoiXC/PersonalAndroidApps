# 记账 App — Android 开发任务清单

> 基于 `docs/记账-Accounting/业务需求.md`，按 Android 开发最佳实践与 `docs/开发规范.md` 整理。

---

## 一、项目初始化

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 1 | 创建 Android 工程（Gradle + Kotlin） | 搭建 Gradle 构建，配置 compileSdk / minSdk / targetSdk | P0 |
| 2 | 配置版本统一管理 | 在 `build.gradle` 中统一管理 SDK 版本与依赖版本 | P0 |
| 3 | 搭建基础分包目录结构 | 按 PBF 分包：`base/`、`data/`、`feature/`、`util/`、`widget/` | P0 |
| 4 | 引入核心依赖 | Room、Navigation、Glide、Gson、AndroidX 等 | P0 |
| 5 | 编写 `BaseActivity` / `BaseFragment` | 封装公共生命周期、懒加载、状态栏等 | P0 |

---

## 二、数据层（data/）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 6 | 定义数据实体（Entity） | `BillEntity` / `AccountEntity` / `TagEntity` — 含字段、默认值 | P0 |
| 7 | 定义 DAO 接口 | `BillDao` / `AccountDao` / `TagDao` — 基础 CRUD + 统计查询 | P0 |
| 8 | 编写 RoomDatabase 子类 | `AppDatabase` — 含数据库名、版本、Migration 策略 | P0 |
| 9 | 初始化默认配置数据 | 预置 5 个操作账户 + 9 个标签（参见需求第五章） | P0 |
| 10 | 创建 Repository 层 | `BillRepository` / `AccountRepository` / `TagRepository` | P0 |
| 11 | 数据导出工具类 | `ExportUtil` — 查询结果转 xlsx，写入 `/download` 目录 | P1 |

---

## 三、主页功能（feature/home）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 12 | 创建 `activity_home.xml` 布局 | 含三个按钮：记账、统计查询、配置 | P0 |
| 13 | `HomeActivity` 实现 | 点击按钮分别导航至对应 Activity | P0 |
| 14 | 可选：主页图标美化 | 为三个入口添加对应图标资源 | P2 |

---

## 四、记账功能（feature/accounting）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 15 | 创建 `activity_accounting.xml` 布局 | 类型（RadioGroup）、操作账户（Spinner）、账户号（EditText）、金额（EditText）、标签（多选 CheckBox）、备注（EditText） | P0 |
| 16 | `AccountingActivity` 实现 | 加载账户/标签列表、类型切换（入账/出账）、操作账户选择联动覆写账户号、表单校验、提交保存 | P0 |
| 17 | 表单校验逻辑 | 类型必选（默认出账）、操作账户必选、金额必填且为数字 | P0 |
| 18 | 操作账户联动 | 选择操作账户时自动填充账户号 EditText | P0 |

---

## 五、统计与查询功能（feature/statistics）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 19 | 创建 `activity_statistics.xml` 布局 | 筛选区域（类型 Spinner / 操作账户 Spinner / 金额范围 EditText / 标签多选 / 日期选择器）+ 结果列表 RecyclerView + 导出按钮 | P0 |
| 20 | `StatisticsActivity` 实现 | 组合筛选、列表展示、日期跨度限制（≤1年）、按年/月快捷选择 | P0 |
| 21 | 金额范围查询逻辑 | 左闭右闭区间 | P0 |
| 22 | 标签多选匹配查询 | 被选中的标签做 OR 或 AND 匹配（按需求"或匹配"） | P0 |
| 23 | 导出按钮 | 调用 `ExportUtil` 生成 xlsx，弹出 Toast 提示导出路径 | P1 |
| 24 | 统计摘要显示（可选） | 在筛选结果上方显示总入账 / 总出账 / 净额 | P2 |

---

## 六、配置功能（feature/config）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 25 | 创建 `activity_config.xml` 布局 | 两个 Section：操作账户管理（含账户号编辑）、标签管理 | P0 |
| 26 | `ConfigActivity` 实现 | 列表展示当前配置，支持新增 / 编辑 / 删除操作账户和标签 | P0 |
| 27 | 默认数据初始化 | 首次安装时写入默认操作账户（5 个）和标签（9 个） | P0 |
| 28 | 配置修改持久化 | 任何配置变更同步写入 Room 数据库 | P0 |

## 七、工具与基础组件

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 29 | xlsx 导出依赖引入 | 引入 Apache POI 或轻量库（如 `org.apache.poi:poi-ooxml`） | P1 |
| 30 | 导出文件权限处理 | Android 10+ 使用 MediaStore 或 SAF；Android 9- 使用 WRITE_EXTERNAL_STORAGE | P1 |
| 31 | 日期工具类 | `DateUtils` — 日期格式化、范围校验、按年/月区间转换 | P0 |
| 32 | 金额输入格式化工具 | `AmountInputFilter` — 限制只能输入数字含小数点 | P0 |
| 33 | 全局 Toast / Snackbar 工具类 | 统一提示 UI | P2 |

## 九、验收标准

| # | 验收项 | 对应任务 |
|---|--------|----------|
| A1 | 首页三个按钮均可正常跳转 | T12–T14 |
| A2 | 手工记账表单校验完整，提交后数据持久化 | T15–T18 |
| A3 | 统计查询按类型/账户/金额/标签/日期组合筛选正确 | T19–T22 |
| A4 | 导出 xlsx 文件生成到 `/download`，文件名格式正确 | T23, T29–T30 |
| A5 | 配置页面可增删改操作账户和标签，改动持久化 | T25–T28 |
| A6 | 默认数据首次安装时正确初始化 | T9, T27 |
| A7 | 日期查询跨度不超过 1 年 | T21, T31 |
| A8 | 选中操作账户时自动覆写账户号 | T18 |

**任务总览：** P0 × 22 | P1 × 7 | P2 × 4

> 建议按优先级顺序推进：P0 → P1 → P2，每个大模块完成后进行冒烟验证。
